# Combine V23 — Virtual Tabletop UI

- Redesigned the in-game screen around the physical-table UI reference supplied by the user.
- Four-sided seating: bottom/left/top/right for 4 players, extended seat layouts for 2–6 players.
- Public hands now sit around the table instead of a dashboard list.
- Player avatars, active-turn indicators, timers, target cards, and draw piles are integrated into the tabletop.
- Bottom player's hand is the interactive hand; selection and expression controls live in a compact dock.
- Scoreboard and recent events are compact overlays so they do not dominate the play area.
- Responsive layouts for desktop and phone screens.
- Preserves the existing Vapourwave + monospace visual system and finalized gameplay rules.
- No Cloudflare changes required for this UI-only revision.
